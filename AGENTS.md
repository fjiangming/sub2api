# Fork maintenance

Read `CUSTOMIZATIONS.md` before changing code or integrating upstream.
Develop on the user's `fjiangming/sub2api` fork's `dev` branch.
Record every source, configuration and test change in that ledger in the same change.
Preserve the documented billing contract and fork release channel when resolving conflicts.
Keep reconciliation, scheduling and operator workflows in `sub2api-extra/operations-center`.
Do not deploy, push, publish or change production data unless the user requests it.
